# Prismattyc 0.2.28 release notes

## Help agents coordinate through pmux

Prismattyc now includes an agent skill with verified guidance for pmux mail,
pane input, sessions, tabs, Spaces, and coordination. Compatible agents can
install it for their user account with `pmux skills install`; enable the
experimental installer by setting `PRISMATTYC_EXPERIMENTAL_PMUX_SKILLS=1`.
